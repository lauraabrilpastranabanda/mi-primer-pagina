¿Qué son las etiquetas semánticas?

Las etiquetas semánticas en HTML se encargan de otorgar un significado claro y específico al contenido que contienen. Más allá de definir un estilo visual, ayudan directamente a los navegadores, lectores de pantalla y motores de búsqueda (SEO) a comprender de forma lógica la organización y el propósito de cada bloque dentro del sitio web.

Etiqueta <header>

Se utiliza para estructurar el encabezado principal de un sitio web o de una sección determinada. Por lo general, agrupa elementos de identidad como el logotipo corporativo, títulos del sitio, barras de navegación o introducciones esenciales.

Ejemplo de uso:

Bienvenido a mi sitio

Inicio | Servicios | Contacto

Etiqueta <section>

Representa una sección genérica y temática dentro del documento. Se emplea para organizar bloques de contenido que guardan relación entre sí, y es una buena práctica que comience siempre con un encabezado jerárquico (h1-h6) que defina su asunto.

Ejemplo de uso:

Noticias Recientes

Aquí se muestran las últimas novedades y artículos relacionados.

Etiqueta <article>

Sirve para empaquetar una composición de contenido independiente y autónoma de la página. Está pensada para elementos que podrían distribuirse o reutilizarse de forma aislada, como entradas de blog, posts en foros, widgets de noticias o reseñas de productos.

Ejemplo de uso:

Nuevo lanzamiento de producto

Hoy presentamos nuestra nueva línea de dispositivos inteligentes.

Etiqueta <aside>

Define una porción de contenido que está tangencialmente relacionada con lo que le rodea, actuando como información secundaria o complementaria. Es perfecta para menús laterales, glosarios, publicidad o conjuntos de enlaces externos.

Ejemplo de uso:

Enlaces relacionados

  • Artículo sobre HTML
  • Guía de CSS
  • Buenas prácticas de accesibilidad

Etiqueta <footer>

Determina el cierre o pie de página de un documento o sección. Comúnmente almacena datos de propiedad intelectual (copyright), avisos legales, accesos rápidos de contacto, enlaces de redes sociales o la fecha de actualización.

Ejemplo de uso:

© 2026 Mi Sitio Web

Contáctanos | Política de Privacidad

Etiqueta <nav>

Su función es delimitar un bloque dedicado exclusivamente a la navegación de la web. Agrupa colecciones de enlaces internos o externos que permiten a los usuarios desplazarse por las distintas pestañas o zonas del documento de forma clara.

Ejemplo de uso:

  • Inicio
  • Servicios
  • Contacto

Etiqueta <main>

Contiene el núcleo central y el contenido predominante de la página web. Debe ser único en el documento, evitando repetir fragmentos compartidos con otras secciones como barras globales de navegación, logos de cabecera o copyrights.

Ejemplo de uso:

Contenido Principal

Este es el texto central de la página, donde se muestra la información más relevante.

Campo de búsqueda en HTML

El uso del atributo type="search" en una etiqueta de entrada de texto (<input>) se utiliza para proveer un área optimizada para búsquedas internas. Permite que los dispositivos móviles y navegadores reconozcan su función nativa, ofreciendo en ocasiones botones para borrar el texto rápidamente.

Etiqueta <address>

Se implementa para proporcionar información de contacto explícita sobre el autor o dueño del sitio o del artículo. Admite todo tipo de datos de localización como direcciones postales, cuentas de e-mail, teléfonos directos o hipervínculos de contacto.
