04 ETIQUETAS SEMÁNTICAS

REGRESAR

Este es el Header (Encabezado)

Aquí suele ir el logotipo de la página o el título principal.

Este es el Nav (Navegación)

Aquí se colocan los menús y enlaces principales para moverse por el sitio web.

Este es el Main (Contenido Principal)

Es el bloque más importante porque contiene el tema central de la página.

Esta es una Section (Sección)

Se utiliza para agrupar contenido que tiene un mismo tema asignado.

Este es un Article (Artículo)

Contenido autónomo, como una noticia, un post de un blog o un comentario.

Este es el Search (Búsqueda)

Aquí se coloca el buscador de la página para encontrar contenido rápidamente.

Este es el Aside (Barra Lateral)

Contenido relacionado de forma indirecta, como publicidad, enlaces rápidos o datos del autor.

Este es el Footer (Pie de Página)

Aquí van los derechos de autor, políticas de privacidad y enlaces legales.

Este es el Address (Contacto)
