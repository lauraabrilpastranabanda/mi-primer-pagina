CSS
Lenguaje para dar estilos a las páginas web.
JavaScript
Lenguaje de programación para páginas web.
Internet
Red mundial de computadoras.
Navegador
Programa para visualizar páginas web.
Servidor
Equipo que almacena sitios web.
URL
Dirección de una página web.
Dominio
Nombre único de un sitio web.
Hosting
Servicio de alojamiento de sitios web.
Responsive
