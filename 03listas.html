JavaScript
Lenguaje enfocado en otorgar dinamismo y lógica del lado del cliente.
PHP
Entorno de programación backend orientado al desarrollo de aplicaciones dinámicas.
SQL
Sistema estructurado para la manipulación y consulta en bases de datos relacionales.

Estructura de interfaz basada en componentes reutilizables sobre JavaScript.

Ecosistema de ejecución que traslada el uso de JavaScript al lado del servidor.
